Porte d'entrée — QR Code

Scannez ou saisissez le lien pour accéder au formulaire de satisfaction.

Wi‑Fi : adresse IP changeante Chaque matin : lancez ipconfig (carte Wi‑Fi), démarrez npm start, ouvrez cette page avec la nouvelle adresse (ex. http://11.11.83.23:5175/acces.html), puis Mettre à jour le QR et réimprimez l'affiche.

Chargement…

Le port peut être 5173, 5174 ou 5175 si d'autres programmes l'utilisent. Regardez la ligne Network dans le terminal après npm start.

Ouvrir l'application

Routine quotidienne

  1. npm start dans borne-satisfaction
  2. Noter l'IP Wi‑Fi et le port (terminal Vite)
  3. Ouvrir /acces.html avec cette adresse → Mettre à jour le QR
  4. Imprimer — le téléphone client doit être sur le même Wi‑Fi
